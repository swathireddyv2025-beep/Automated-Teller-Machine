An Automated Teller Machine (ATM) System is designed to provide banking services to customers without requiring assistance from bank staff. The system allows customers to access their bank accounts using an ATM card and a Personal Identification Number (PIN). After successful authentication, customers can perform various banking transactions such as cash withdrawal, cash deposit, balance inquiry, mini statement, PIN change, and fund transfer.
The ATM system must verify the customer's credentials, process transactions securely, update account balances in real time, and maintain transaction records. It should ensure that sufficient account balance and ATM cash availability are checked before dispensing cash. The system should also provide appropriate error messages for invalid PINs, insufficient balance, or unavailable services.
